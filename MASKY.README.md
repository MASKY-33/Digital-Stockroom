# Digital Stockroom
This system stores product categories with their stock quantities and allows the user to check availability.
It also demonstrates how to add new items and update existing stock levels inside a dictionary.

## Features
- Stores products and their quantities in a dictionary
- Prints the stock of a specific item (“phones”)
- Adds a new product to the stockroom
- Updates the quantity of an existing product
- Checks if a searched product exists
- Shows the quantity if found
- Gives a clear message if the product is not in stock

# How to use
Run the system and type the name of any product you want to check.
The program will display the stock quantity or tell you if the product is unavailable.


## Learning Purpose
This project was created as part of backend engineering practice.
The goal was to improve skills in:
- dictionaries
- updating and adding data
- conditional logic
- input handling
- simple system architecture
